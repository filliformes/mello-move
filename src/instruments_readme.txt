MELLO SAMPLE LIBRARIES
======================

Drop WAV sample banks in these folders, one bank per sub-folder:

  instruments/
    MT/                <- MellowTrawn (full Leisureland archive, 129 banks)
      M400-Cello/
        M400Cello-1.wav
        ...
    SB/                <- Sonic Bloom Mellotron pack (23 banks)
      MK2 Flute/
        A2-3.wav
        ...
    90/                <- 90s Mellotron Archive CD (28 banks)
    YourOwnLibrary/    <- any folder you create appears as a new library

Accepted filename conventions (one note per WAV, 16-bit PCM):
  A2.wav / C#3.wav / Bb4.wav    note name + octave (C4 = MIDI 60)
  60.wav                        bare MIDI number
  MyBank-8.wav                  sequential index (Seq Base param, default 40:
                                -1.wav = F2, -8.wav = C3, -20.wav = C4)

Where to find the free libraries:
  MellowTrawn / Leisureland:  http://www.leisureland.us/mellotron.htm
  Sonic Bloom:                https://sonicbloom.net/free-sb-mellotron-samples/
  90s Archive CD:             circulated in the Mellotron community

After adding banks, power-cycle the Move so the bank list refreshes.
